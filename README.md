# Portfolio — God-Louange Thombet-Kende

Portfolio personnel d'apprenti **Data Analyst** (BUT Science des Données, parcours VCOD).

Page web statique, responsive, avec animation de fond et sections : à propos, compétences, parcours, expériences en parallèle, projets et contact.

## Aperçu local
Ouvrir `index.html` dans un navigateur.

## Structure
- `index.html` — la page complète (HTML, CSS et JS dans un seul fichier)
- `profil.jpg` — photo de profil
- `logos/` — logos des entreprises (déposer `mcdonalds.png`, `mtn.png`, `batisse.png`, `leclerc.png`)

## Stack
HTML · CSS · JavaScript (vanilla) — aucune dépendance.
